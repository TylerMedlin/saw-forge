Install guide

Installing Saw Forge

Every screen you'll see, from download to making music, in about two minutes.

1

Download the installer

Get SawForgeHub-Setup-win-x64.exe from the download page. It's a single setup file for Windows 10 and 11 (64-bit).

Download for Windows

2

Open the installer

Open the file from your browser's downloads, or from the Downloads folder.

If you see “Windows protected your PC”: click More info, check that the publisher reads “Unknown publisher” and the file name matches, then click Run anyway. This is Microsoft SmartScreen; it appears for new apps that aren't code-signed yet. To check the file first, verify its checksum.

Windows then asks if you want to allow the app to make changes only if you choose to install for all users in the next step.

3

Go through the setup wizard

WelcomeSaw Forge Hub Setup. Click Next.
License AgreementThe GNU GPL v3, which explains your freedom to use, share and change the software. Click I Agree.
Installation optionsChoose Only for me (recommended, no admin rights) or Anyone who uses this computer.
Install locationThe default is fine: %LOCALAPPDATA%\Programs\Saw Forge Hub (or Program Files when installing for everyone).
InstallingCopies the files; takes a few seconds.
FinishLeave Run Saw Forge Hub checked and click Finish.

You also get a desktop shortcut and Start → Saw Forge → Saw Forge Hub.

4

Install Saw Forge Studio from the hub

In Saw Forge Hub, click Install next to Saw Forge Studio. The hub downloads the app, checks it against its published checksum, and installs it. When it finishes, click Open.

Saw Forge Studio also gets its own shortcut under Start → Saw Forge (and on the desktop, which you can turn off in the hub's Settings).

5

Start making music

  • Click Demo session on the welcome screen to hear what's possible, or New project to start fresh.
  • Projects save to Documents\Saw Forge\Saw Forge Studio. Ctrl+S saves, and work is autosaved every few seconds.
  • The first time you record, Windows may ask for microphone access. Allow it under Settings → Privacy & security → Microphone.
?

Updating and uninstalling

  • Updates appear in the hub under Updates. The hub updates itself and asks you to restart.
  • To remove one app, use ⋯ → Uninstall in the hub.
  • To remove everything, go to Settings → Apps → Installed apps → Saw Forge Hub → Uninstall. This removes the hub, its apps and their shortcuts. Your projects in Documents are kept.
1

Download the disk image

Get SawForgeHub-mac-universal.dmg from the download page. One download works on Apple Silicon (M1 and later) and Intel Macs running macOS 12 Monterey or later.

Download for macOS

2

Drag Saw Forge Hub into Applications

Double-click the downloaded .dmg. In the window that opens, drag the Saw Forge Hub icon onto the Applications folder. Then eject the disk image (the ⏏ button in Finder's sidebar).

3

Open it the first time

Open Saw Forge Hub from Applications or Launchpad.

If macOS says it can't verify the app: early releases aren't notarized by Apple yet, so the first launch needs one extra approval.
  • macOS 15 Sequoia and later: click Done, open System Settings → Privacy & Security, scroll to Security, click Open Anyway next to “Saw Forge Hub was blocked”, and confirm with your password.
  • macOS 12–14: Control-click (or right-click) Saw Forge Hub in Applications, choose Open, then click Open again.
You only need to do this once. To check the file first, verify its checksum.
4

Install Saw Forge Studio from the hub

Click Install next to Saw Forge Studio. The hub downloads it, checks its checksum and installs it. Then click Open. Keep Saw Forge Hub in the Dock to reach your apps quickly.

5

Start making music

  • Click Demo session on the welcome screen to hear what's possible, or New project to start fresh.
  • Projects save to Documents/Saw Forge/Saw Forge Studio. ⌘+S saves, and work is autosaved every few seconds.
  • The first time you record, macOS asks for microphone access. Click Allow, or change it later in System Settings → Privacy & Security → Microphone.
?

Updating and uninstalling

  • Updates appear in the hub under Updates. Once releases are signed, the hub also updates itself; until then, download new hub versions from this site.
  • To remove one app, use ⋯ → Uninstall in the hub.
  • To remove everything, uninstall the apps in the hub, quit it, and drag Saw Forge Hub from Applications to the Trash. Settings live in ~/Library/Application Support/Saw Forge Hub. Your projects in Documents are kept.
